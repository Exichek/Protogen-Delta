# Загрузчик видео

`/download` и Mini App используют один `MediaDownloader` для YouTube, Instagram,
TikTok, Vimeo, VK/VK Видео и X/Twitter. GIF поддерживаются только из X.

Общие пределы: один ролик до 600 секунд и 100 МиБ входа, два обработчика,
240 секунд на загрузку и преобразование. Файл до 49 000 000 байт отправляется
без перекодирования. Больший файл сжимается в H.264/AAC с целевым размером
43 МБ и запасом до лимита Telegram. Это применяется ко всем площадкам.
Слишком большой вход отклоняется до кодирования, известная чрезмерная
длительность — до скачивания. Сжатие может снижать качество.

Worker передаёт родителю только ограниченный код ошибки: проверка YouTube
«не бот», требование возраста/входа, недоступность, размер, длительность,
неподходящий формат, HTTP 403/429, сеть, runtime, сессия или сжатие.
Исходные сообщения сайта, подписанные ссылки и содержимое cookies в ответ,
промпт и логи не включаются. Для неизвестного отказа остаётся общий ответ.

## YouTube и JavaScript

Зафиксированы `yt-dlp==2026.8.19`, `yt-dlp-ejs==0.8.0`, `deno==2.9.7`.
yt-dlp загружает официальный комплект EJS из установленного пакета;
скачивание исполняемых компонентов во время запроса отключено.
Основание: [EJS Setup Guide](https://github.com/yt-dlp/yt-dlp/wiki/EJS).

Audit hook разрешает только установленный бинарник Deno: проверку версии
либо `run` со строго известными флагами и скриптом через stdin. Разрешения
на файлы, сеть, переменные окружения и запуск процессов скрипту не выдаются.
Shell, внешние загрузчики и FFmpeg остаются запрещены. V8 heap ограничен
128 МиБ. На Linux этап метаданных имеет RLIMIT_DATA 1 ГиБ, CPU 180 секунд,
запрещённые core dump; ограничение виртуального адресного пространства
мешало бы резервированию V8. После извлечения метаданных до обработки
видеофайла возвращается RLIMIT_AS 2 ГиБ. Обычные площадки используют его
с начала worker. Windows использует общий таймаут и ограничения V8.

При отмене родитель завершает дерево процессов. На POSIX сначала посылается
SIGTERM: Python прерывает ожидание EJS, закрывает и reap выполняющийся Deno.
Через две секунды применяется SIGKILL, если нужен принудительный останов.
На Windows используется taskkill /T /F. Завершение защищено от повторной
отмены; временный каталог удаляется после остановки.

## Необязательная сессия YouTube

По умолчанию загрузчик работает анонимно. Подключение сессии не гарантирует
доступ ко всем роликам и не отменяет ограничения размера, длительности,
закрытого контента или самого сайта. Вход применяется только к YouTube.

1. Подготовьте отдельный аккаунт, который сам открывает нужный ролик и при
   необходимости подтвердил возраст. Экспортируйте cookies YouTube в формате
   Netscape по [официальной инструкции yt-dlp](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies).
2. Сохраните файл приватно, например `.secrets/youtube-cookies.txt`.
   `.secrets` исключена из Git и Docker build context. Не включайте файл в PR.
3. Для Compose задайте в приватном `.env`:

   ```dotenv
   YOUTUBE_COOKIES_HOST_FILE=/home/exi/protogen-delta/.secrets/youtube-cookies.txt
   YOUTUBE_COOKIES_FILE=/run/secrets/youtube_cookies
   ```

4. Файл на хосте должен быть доступен UID пользователя `protogen` из образа,
   с режимом 0600. Определите UID командой `docker compose exec -T delta id -u`
   и выставьте владельца на этот UID средствами администратора. Файл
   монтируется как secret только для чтения. Затем пересоздайте `delta`.

При пустом `YOUTUBE_COOKIES_HOST_FILE` монтируется безопасный файл-заглушка.
Пока `YOUTUBE_COOKIES_FILE` пуст, заглушка не используется для входа.
Для запуска без Compose настройка может указывать на доступный приватный файл.

На каждый YouTube-запрос создаётся копия до 256 КиБ в приватном временном
каталоге, режим 0600. Истёкшие cookies и домены вне youtube.com удаляются.
Cookies других аккаунтов/площадок не передаются yt-dlp. Исходный файл
не перезаписывается; временная копия удаляется после запроса. Копирование
дожидается завершения при отмене, поэтому файл не возникает после cleanup.
Сессия может истечь — тогда нужно повторно экспортировать и подключить файл.
