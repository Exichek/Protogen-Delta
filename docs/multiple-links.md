# Несколько публичных ссылок

При явной просьбе прочитать или сравнить несколько ссылок, а также при сообщении
только из нескольких ссылок, приложение открывает первые шесть уникальных адресов
параллельно обычным защищённым инструментом `fetch_web_page`. Каждая попытка входит
в общий предел шести обращений к инструментам на этот ответ. Страница, требующая
авторизацию, недоступный сайт или неподдерживаемый формат могут не прочитаться.

Модель получает ограниченный текст и результаты по каждой странице. В ответ
приложение добавляет фактические статусы: текст получен, страница недоступна,
получены только метаданные ролика или метаданные и субтитры. Субтитры не означают
просмотр видеоряда. При превышении шести адресов остаток явно отмечается непроверенным.
Цитаты, код и содержимое вложенного документа сами по себе не запускают этот режим;
явный запрет открывать ссылки также его отключает.

Независимые известные инструменты чтения в одном ответе модели тоже выполняются
параллельно, сохраняя порядок результатов и `tool_call_id`. Прочие инструменты
выполняются последовательно. Когда модель продолжает требовать инструменты после
исчерпания шагов, делается один заключительный запрос без их схем по собранным
данным. Все LLM-попытки, включая заключительную, учитываются в суточном лимите.

`/download` по-прежнему принимает одну ссылку на видео; это отдельная функция,
не просмотр текста всех страниц. Подставные тесты проверяют параллельность,
частичную недоступность, бюджет и ограничения контекста без настоящих сайтов и LLM.
