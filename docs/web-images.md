# Картинки из интернета в личном чате

По явной просьбе «скинь фотку из интернета по игре» модель получает инструмент
send_web_image. Обычный поиск остаётся прежним: DeepSeek Search, Brave в резерве,
общие кеш и квоты. Страница выбирается через поиск; инструмент принимает её
публичный URL или прямую ссылку на изображение. Новый поисковый провайдер не нужен.

Инструмент читает страницу своим ограниченным публичным загрузчиком и пробует
до трёх основных изображений: Open Graph/Twitter, затем подходящие img.
Относительные адреса разрешаются относительно конечной страницы. Скрипты,
SVG, data URL и credentials не используются. Каждый запрос, DNS и redirect
проходит существующую защиту от локальных и служебных адресов, включая прокси.
Страницы, требующие входа, JavaScript или запрещающие загрузку, могут быть недоступны.

Максимум загрузки — 3 МиБ на ответ HTTP. JPEG, PNG, WebP и первый кадр GIF
декодируются Pillow: до 20 мегапикселей, минимум 128 пикселей по каждой стороне,
соотношение сторон до 20. Результат приводится к JPEG с белой подложкой,
без EXIF и размером до 1920×1920 и 3 МиБ. Это подготовка готовой картинки,
не генерация и не анализ её содержания моделью. Ограничения Telegram описаны
в [официальном Bot API](https://core.telegram.org/bots/api#sendphoto).

Файл передаётся в sendPhoto как байты; Telegram не получает произвольный URL
для самостоятельной загрузки. Подпись содержит название страницы и источник.
Назначение фиксируется приложением по текущему владельцу личного диалога:
у модели нет параметров выбора получателя. В черновике, пересылке, обычном
фактическом вопросе, фоновой генерации и группе инструмент отправки закрыт.
Просьба только о ссылке или генерации изображения не разрешает отправку файла.

В одном ходе допускается до трёх попыток. Повтор файла с тем же SHA-256 не
создаёт второе фото. После неопределённой доставки автоматических повторов нет.
Таймаут Telegram — восемь секунд; для этого инструмента общий предел — 20 секунд
на загрузку, подготовку и отправку. Остальные инструменты сохраняют прежний таймаут. При отмене начатая отправка завершается,
а подтверждение сохраняется до восстановления отмены. Повторять такой вызов
после отмены нельзя. Число одновременных загрузок ограничено двумя.

Только подтверждённый sendPhoto возвращает status=sent и создаёт запись
«Подтверждённая отправка фото» в истории успешного ответа. Общий журнал
исходящих сообщений также видит фактически отправленную подпись: фото не
пропадает из контекста при последующем сбое текстового ответа. На проваленной
попытке приложение не позволяет выдать за результат фразу «отправил картинку».
Успешная отправка прямого изображения без прочитанной текстовой страницы
подтверждается фиксированной фразой, без непроверенных подробностей о картинке.

Инструментальный цикл сохраняет четыре раунда и шесть вызовов инструментов.
Для просьбы без URL сначала выполняется поиск и проверка страницы, затем
выбирается send_web_image. Известный прямой URL можно отправить сразу.
Подключённые возможности теперь явно отличают отправку готовой картинки от
отсутствующего сервиса генерации изображений.

Проверены подменённый транспорт Telegram, фактический цикл SDK, изоляция
получателя, неудачные загрузки, повтор, отмена, прямые URL, формат и размеры.
Открытая страница Cyberpunk 2077 из пользовательского примера проверена реальным
HTTP-запросом: получен JPEG 1920×1080, 404426 байт. В этой проверке Telegram,
поисковые API и модель не вызывались.
