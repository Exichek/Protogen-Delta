# Новые медиа-модули

## Видео по ссылке

`/download https://www.youtube.com/watch?v=...` скачивает одно публичное видео.
Поддерживаются точные HTTPS-хосты YouTube, Instagram, TikTok, Vimeo, X/Twitter и VK; обычная
ссылка в разговоре не запускает загрузку. Лимиты: 10 минут, 45 МБ, 120 секунд,
два одновременных worker-процесса и 30 секунд между запросами пользователя.
Для X/Twitter нужна ссылка на публичный пост с видео, например `/download https://x.com/captainamerica/status/719944021058060289`.
Поддерживаются адреса x.com и twitter.com, включая мобильные варианты и `/video/1`.
Пост без видео, приватный/удалённый пост или видео, требующее входа, загрузить нельзя.
MP4 отправляется как видео, другие контейнеры — как файл. Для YouTube отдельные
потоки до 720p объединяются PyAV без перекодирования; временно на диске может
быть до двух размеров файла (исходники и результат).

Worker не получает секреты приложения, не использует cookies и внешние
downloader-процессы. Socket audit hook блокирует соединения с неглобальными IP,
включая redirect на loopback/LAN. Файлы удаляются при успехе, сбое и отмене.
Используется [yt-dlp](https://github.com/yt-dlp/yt-dlp), версия закреплена в lock.
Доступность зависит от сайта и IP сервера; вход в аккаунт, DRM и блокировки
не обходятся. При изменении сайта может понадобиться обновление зависимости.

Для VK подойдут прямые ссылки `https://vk.com/video-123_456`,
`https://vk.ru/clip-123_456`, `https://vkvideo.ru/video-123_456`,
мобильные ссылки и ссылки плеера `video_ext.php?oid=...&id=...&hash=...`.
Префикс `www` нормализуется перед запуском экстрактора; параметры видео сохраняются.
Публикация должна открываться без входа в аккаунт. Эти же ссылки принимает
загрузчик во вкладке «Полезное» Mini App.

## Сканированные PDF

`PDF_OCR_ENABLED=true` включает локальный Tesseract с языками `rus+eng`.
Docker-образ уже устанавливает необходимые пакеты. При запуске через Python
Tesseract нужно установить отдельно и добавить в PATH.

PDFium рендерит целую страницу до 2048 пикселей; OCR выполняется вне event loop,
последовательно, без передачи страницы внешнему сервису. Лимиты: первые 40
страниц, общий бюджет 90 секунд (текущая страница может добавить до 15 секунд),
60 000 символов. При недоступном OCR остаются до четырёх scan-изображений для
vision. Пропущенные страницы явно помечаются; бот не считает их прочитанными.

## Содержание музыки

Основная chat-модель не получает необработанный трек. Отдельный модуль принимает
первые 60 секунд, преобразует их в mono PCM16 WAV 16 kHz и обращается к
аудиомодели: один запрос, максимум 600 выходных токенов и 45 секунд.
Описание жанра, инструментов, вокала и изменений считается предположением.
Название трека и исполнитель не угадываются. Распознавание речи и измерения
сигнала продолжают работать, если аудиосервис выключен или недоступен.

Настройки:

```dotenv
AUDIO_UNDERSTANDING_ENABLED=true
AUDIO_API_KEY=<ключ отдельного провайдера>
AUDIO_BASE_URL=<HTTPS OpenAI-compatible endpoint>
AUDIO_MODEL=<модель с input_audio и streaming text>
AUDIO_INPUT_DATA_URL=false
```

По умолчанию WAV передаётся как чистый base64, как требует
[OpenRouter](https://openrouter.ai/docs/guides/overview/multimodal/audio).
Для [Qwen-Omni](https://www.alibabacloud.com/help/en/model-studio/qwen-omni)
укажите `AUDIO_INPUT_DATA_URL=true`: данные будут иметь префикс `data:;base64,`.
Конкретные endpoint, модель и ключ выбираются для региона аккаунта. Обычной
текстовой модели недостаточно. До настройки сервис выключен; история диалога
и личность Дельты в этот дополнительный запрос не передаются.

Для Nemotron через OpenRouter:

```dotenv
AUDIO_BASE_URL=https://openrouter.ai/api/v1
AUDIO_MODEL=nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free
AUDIO_INPUT_DATA_URL=false
```

У варианта `:free` нулевая цена токенов, но живая проверка OpenRouter выявила
требование баланса от $0.50 для аудиозапросов (HTTP 402 без баланса).
Для бесплатной модели приложение ограничивает цену провайдера нулём и выключает
дополнительное reasoning, чтобы ответ помещался в бюджет 600 токенов.
Смена на платную модель или автоматическое платное резервирование не выполняется.

## Источник арта

Reply `/source` на фото запускает поиск похожих публикаций через SauceNAO.
Нужен `SAUCENAO_API_KEY` из [панели сервиса](https://saucenao.com/user.php?page=search-api).
Внешнему сервису отправляется JPEG до 1024 пикселей без исходных метаданных.
Автоматически каждое фото никуда не отправляется. Выводятся до трёх HTTPS-ссылок
с числовым сходством от 80%; это кандидаты, не доказательство источника.
Инструмент не идентифицирует людей по лицу и не гарантирует определение игрового
персонажа, если публикация отсутствует в индексах.

Проверка формата API выполнена тестами на ответах; живой запрос ожидает ключ.
Нет универсального обратного поиска всего интернета: индекс SauceNAO ограничен.

## Замена Brave-ключа

Новый ключ нужно выдать в [панели Brave Search API](https://api-dashboard.search.brave.com/).
В Windows выполнить `./scripts/set-brave-key.ps1`: ввод скрыт, ключ сохраняется
в `.secrets/brave_api_key`, старое значение в `.env` очищается. Затем перезапустить
бота, проверить поиск и отозвать прежний опубликованный ключ в панели.

Для Linux ключ можно сохранить в закрытый файл (`chmod 600`) и указать
`BRAVE_SEARCH_API_KEY_FILE`. Файл имеет приоритет над переменной с прежним ключом.
Для Docker файл следует смонтировать read-only и указать путь внутри контейнера.
Ни установка новой переменной, ни этот скрипт сами по себе не отзывают ключ у
Brave: ротация завершена только после отзыва старого ключа.

## Основной веб-поиск и резерв

Основной поставщик — DeepSeek Search, резервный — Brave. Реестр сохраняет
`web_search` и `fetch_web_page`; разговор и мировая лента «Рынков» используют
один экземпляр сервиса с общим кешем и бюджетом. Пустая выдача не считается
ошибкой и не запускает второй платный поиск. При сетевой ошибке, ошибке API
или некорректной выдаче разрешена одна попытка Brave. После ошибок источник
ненадолго приостанавливается; при ошибке ключа или баланса — на час.

Отбор инструментов учитывает разговорные просьбы: «найди последнюю инфу»,
«поищи информацию», «найди сведения», «в инете посмотри». В обычном разговоре
поиск и чтение страниц доступны также без ключевых слов: модель должна сама
проверять неизвестные или сомнительные внешние факты. Это решение модели,
а не гарантия её точности; уверенный ошибочный ответ всё ещё возможен.
Для приветствия, шутки, личной переписки или RP поиск сам по себе не нужен.
Наличие схем не вызывает сеть и не добавляет отдельного классификатора.
Просьба «без поиска» отключает поиск в этом ходе; явную ссылку по-прежнему
можно прочитать. RP, обзор возможностей и чужие пересылки не получают
дополнительные схемы автоматически. При выборе поиска одновременно доступно
чтение найденных публичных страниц. Это не открывает доступ к исходникам,
переписке или другим инструментам: их разрешения проверяются отдельно.

Уточнение «что ещё на сайте» привязывается к ссылкам последнего хода, без
поиска подходящего сайта в старых темах. Если ссылок несколько, бот спрашивает
выбор; можно ответить номером, доменом или попросить разобрать все. Исправление
вроде «анализируй*» сохраняет цель предыдущей просьбы, даже если ответ на неё
уже ошибочно сменил тему. Ссылка из ответа не считается доказательством чтения:
выбранная страница запрашивается через `fetch_web_page`. RP, вложения и явная
цитата-ответ не получают такую автоматическую подстановку.

Включение: `DEEPSEEK_SEARCH_ENABLED=true`. Ключ берётся из настройки основного
LLM только при официальном адресе DeepSeek и выбранном провайдере `deepseek`.
Сторонний OpenAI-совместимый ключ не передаётся DeepSeek. Для отдельной
авторизации предусмотрен `DEEPSEEK_SEARCH_API_KEY`; он не выводится в логи.
При выключении DeepSeek Brave может продолжать работать самостоятельно.

Короткий запрос — 2–100 символов, до 10 результатов. Язык и свежесть переводятся
в операторы `lang:` и `after:`; весь запрос укладывается в 128 символов.
Даты и описания приходят от поискового поставщика, не доказывают дату
публикации и не означают, что приложение прочитало страницу.

Страницы сначала читает существующий загрузчик. DeepSeek Fetch используется
при ошибке или пустом тексте. YouTube сохраняет свой специализированный путь.
Локальные адреса, credentials в URL и redirect на запрещённый адрес не уходят
в резервный Fetch. Он возвращает Markdown, ограниченный 12 000 символов.
Поставщик не возвращает итоговый URL, поэтому результат явно отмечает,
что адрес после перенаправлений не подтверждён.

`WEB_API_DAILY_LIMIT=200` — общий предел попыток всех веб-API на весь бот
за московские сутки, отдельно от вызовов модели. Неудачные попытки тоже
расходуют этот локальный предел: он консервативно ограничивает расходы,
а не воспроизводит счёт провайдера. Максимальная стоимость 200 успешных
запросов именно DeepSeek при текущей цене — $0,15, без токенов модели.
`BRAVE_MONTHLY_SEARCH_LIMIT=1000` дополнительно ограничивает резерв Brave
за календарный месяц по Москве. Счётчик знает только обращения этого
приложения после установки; прежние расходы, другие клиенты и расчётный
период Brave надо проверять в кабинете провайдера. Он не гарантирует
остаток бесплатного кредита аккаунта.

Счётчики атомарно сохраняются в `llm_usage.db`, таблица `web_api_usage`
содержит только день, поставщика, вид операции и количество попыток.
Тексты запросов, URL, ключи и Telegram ID в неё не записываются. При
недоступном учёте внешние запросы не выполняются. База уже включена
в существующее резервирование.

Кеш публичных результатов находится только в памяти: до 128 записей
по пять минут. Совпадающие параллельные обращения объединяются; попадания
в кеш не расходуют квоту. Одновременно загружаются не больше двух результатов,
очередь ограничена 32 задачами. DeepSeek Search и Fetch ограничены отдельно
интервалом 0,3 секунды, Brave — одной секундой. Перезапуск очищает кеш,
но сохраняет счётчики.

[DeepSeek Search & Fetch](https://api-docs.deepseek.com/guides/search/) —
отдельные HTTP API, оплата успешных запросов. Бесплатный период серверных
инструментов агентских клиентов не означает бесплатные прямые обращения.
Фактический тариф проверяется на [странице цен](https://api-docs.deepseek.com/quick_start/pricing/).
