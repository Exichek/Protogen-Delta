# Проверка возврата в диалог после инициативы

18.10.2026 проверены обезличенные метаданные обоих аккаунтов создателя без чтения
текстов переписки, вызовов модели, изменения настроек или принудительной отправки.

На тестовом аккаунте счётчик `unanswered_count` был равен нулю, инициатива разрешена,
доставка не приостановлена, новый срок был назначен после последнего сообщения
пользователя. Лимит предыдущего дня не блокировал новый день. На другом аккаунте
счётчик был равен единице: последняя самостоятельная реплика оставалась без ответа.
Зафиксированного залипания сброса не обнаружено.

Счётчик отсутствия ответа уже сбрасывается входящим middleware для любого нового
сообщения в личном чате, включая фото. Обычный доставленный ответ Дельты переносит
начало интервала тишины, но сам не изображает ответ пользователя. Старый срок
очищается, новый выбирается один раз в диапазоне 1,5–3 часа. В текущей инициативе
после этого также действуют побуждение, минимальная дистанция между самостоятельными
отправками, максимум две отправки в московские сутки и тихие часы 23:00–09:00.
Ночная пауза может быть длиннее десяти часов. Даже наступивший срок допускает
решение модели промолчать; это не гарантированное напоминание.

Добавлены регрессии полного цикла на временной SQLite с управляемыми часами:

- самостоятельное сообщение → десять часов без ответа → текст или фото от
  пользователя → обычный ответ → новый интервал → ещё одна самостоятельная реплика;
- тот же цикл с восстановлением всех сервисов из сохранённых данных;
- вечерний ответ → запрет ночной отправки → возобновление утром;
- ответ сбрасывает ожидание ответа, сохраняя суточный предел и явное отключение
  инициативы пользователем;
- без нового ответа после второй инициативы дальнейшие отправки прекращаются.

Проверки используют подставные модель и Telegram. Они подтверждают планировщик и
сброс ожидания, а не естественность свободного текста. Неоднозначное узнавание
брюк как куртки относится к качеству зрения; натянутая отсылка к кружке — к качеству
генерации. По этим двум примерам настройки голоса и RP не переписывались.
