# Кандидат понятных самостоятельных сообщений

Статус: подготовлен локально, на сервер не установлен. Платный сравнительный
прогон не выполнен; запрошено отдельное разрешение до 16 вызовов модели.

В живом режиме `request = plan.request()` заменял подготовленное задание
вместе с недавними репликами чата. Проверка почти дословных повторов после
генерации оставалась, но сами прежние инициативы в запрос не попадали.
В результате инструкция «не повторяй» не давала модели конкретных сообщений,
которые нужно отличить от нового. Это подтверждённый дефект передачи контекста;
его наличие не доказывает единственную причину неестественного текста.

Кандидат передаёт три последние незакрытые инициативы отдельно от задания,
как JSON с цитатами данных. Для этого списка исключаются личные темы,
действующие ограничения не меняются. Старые тексты служат для неповторения
темы, образа и формата игры, а не для восстановления фактов или занятий
между сообщениями. Обычная история и закрытые сцены этим списком не передаются.

Для новой мысли убрано обязательное предложение необычного ракурса на бытовой
предмет. У всех поводов добавлена проверка понятности: одна связная мысль,
юмор по желанию, упрощение или молчание вместо шутки, требующей расшифровки.
У игры должны быть понятные правила и одно ненавязчивое приглашение.
Новых образцов реплик и запретов по отдельным словам нет. Дополнительный
проверочный вызов модели при каждой инициативе не добавляется.

Основной системный промпт, личность, голос, RP, вероятности выбора поводов,
расписание и квоты сохранены. Отдельный контекст прежних инициатив не попадает
в приглашение продолжить активную RP-сцену.

Локально прошли 232 целевые проверки: передача реальному пути генерации,
ограничение объёма, закрытые и личные темы, различение цитаты и инструкции,
RP, инициативы, возврат пользователя и утреннее расписание. Линтер и проверка
типов изменённых файлов прошли. Эти проверки подтверждают устройство запроса,
но не качество новых ответов модели.

## План сравнения после разрешения

Восемь синтетических ситуаций, по одному ответу прежнего и нового варианта:
спокойная новая мысль; игривая новая мысль; новая игра; игра после похожего
прошлого приглашения; спокойное настроение; выраженная радость; отсылка
к придуманной для теста шутке; приглашение продолжить нейтральную RP-сцену.
Состояние, выбранный повод, время и история совпадают внутри каждой пары.

Проверять вручную: понятность без пояснения, связность, отсутствие выдуманного
события из своей жизни, повторов старого образа и давления начать игру,
сохранение характера. Молчание допустимо, но постоянное молчание не считается
улучшением. Один ответ на условие не позволяет гарантировать естественность.

До 16 попыток обращения к API, без автоматических повторов, инструментов,
веб-поиска, Telegram и рабочей истории. Использовать отдельное временное
состояние, не менять личные квоты. Предыдущий бюджет 32/32 уже использован.
Решение об установке принимать по прочитанным ответам, а не по числу тестов.
