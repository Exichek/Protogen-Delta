# Общий суточный потолок API

`LLM_GLOBAL_DAILY_REQUEST_LIMIT=3000` ограничивает суммарные попытки API
работающего бота. Личная квота 300 и персональные исключения (например, 1000)
сохраняются. Чтобы отправить запрос, должны одновременно оставаться обе квоты.
Единица — попытка API, включая служебную классификацию и каждый сетевой retry,
а не сообщение Telegram. Это ограничение числа запросов, не фиксированная сумма
в деньгах: объём входных и выходных токенов различается.

Проверка суммы за московские сутки и резервирование личной попытки происходят
в одной SQLite-транзакции `BEGIN IMMEDIATE`. Отказ одной квоты откатывает всю
транзакцию. Параллельные аккаунты и процессы с общей базой не превышают потолок.
Сброс суток — 00:00 по Москве; запоздавшие usage записываются в исходный день.
Сумма берётся из существующих суточных строк: включение потолка не обнуляет
ранее использованные попытки или токены. Отдельный индекс ускоряет сумму дня.

Вызовы без `current_llm_user` также учитываются, под служебным ключом 0.
Он не является Telegram-аккаунтом и не получает чужую персональную квоту.
Отсутствие настроенного репозитория у изолированного тестового стенда остаётся
отдельным режимом; платные оценочные пробы требуют собственного разрешения.
Учёт не содержит текстов запросов. Недоступность SQLite блокирует платный вызов.

Необязательный `LLM_BUDGET_ALERT_USER_ID` указывает владельца уведомлений.
Раз в минуту фоновый обработчик проверяет пороги 80% и 100%. Отправляется
статический текст с общими числами и датой, без модели, имён и переписки.
Попытка доставки отмечается в SQLite до отправки, поэтому рестарт не создаёт
дубликаты. При скачке сразу к 100% более низкий сигнал подавляется. Сетевой
сбой может оставить исход доставки неизвестным; повторный сигнал на тот же
порог не отправляется, ошибка фиксируется в журнале. Уведомление не является
механизмом ограничения: потолок работает независимо от Telegram и обработчика.

Неплатные команды, очистка данных и возрастная защита работают при исчерпанном
потолке. Новым аккаунтам отдельная сниженная квота не вводится: остаётся 300.
Общие расходы не добавлены в публичный пользовательский API Mini App.
