# Распознавание трека без AudD

По умолчанию используется ShazamIO через неофициальный API Shazam. Подписка и ключ
AudD для этого режима не нужны. `MUSIC_RECOGNITION_PROVIDER` выбирает `shazam`,
`audd` или `off`; автоматического перехода на AudD при ошибке нет. AudD остаётся
доступен только при явном выборе и наличии его ключа.

На Python 3.14 опубликованный ShazamIO 0.8.1 требует старый shazamio-core 1.1.2,
для которого нет подходящего готового пакета. Поэтому используется архив
[коммита f94faafdabff9cdec258f3ac024a6402989e9040](https://github.com/shazamio/ShazamIO/commit/f94faafdabff9cdec258f3ac024a6402989e9040)
версии 0.9.0, с shazamio-core 2.0.0. URL, версия и SHA-256 архива закреплены в
Poetry lock. Остальные ранее закреплённые пакеты не обновляются.

Существующий дочерний обработчик подготавливает первые 12 секунд PCM16 mono WAV.
ShazamIO вычисляет отпечаток, наш транспорт отправляет один запрос распознавания.
Ограничения: две операции одновременно, 20 секунд сети, максимум 128 КиБ ответа,
без повторов и редиректов. Допустимы только HTTPS-адреса Shazam, заданные SDK.
История чата, Telegram URL и ключ AudD в запрос не передаются.

Из ответа разрешены название, исполнитель, альбом и дата выпуска. Отсутствие
совпадения не заменяется догадкой. Фильтр `max_skew=1e-3` может отклонять ускоренную
или изменённую по высоте запись; распознавание не гарантирует точность. Информация
сервиса передаётся модели как данные с названием провайдера, а не инструкции.

Нормализация, теги файла, Whisper и описание аудиомодели сохраняют отдельные этапы
и бюджеты. Сбой Shazam не отменяет разбор речи или доступных сведений о записи.
Обычные голосовые сообщения не запускают определение трека.

Перед интеграцией закреплённая библиотека проверена в одноразовом контейнере
Python 3.14 на публичном примере `Gloria.ogg` из её репозитория: ответ —
Gloria Gaynor, I Will Survive, около 0,85 секунды. Это отдельный пример,
а не оценка общей точности. Модульные тесты работают без сети и платных API.

Наш адаптер дополнительно проверен в отдельном образе с настоящим дочерним
обработчиком и ограничением контейнера в одно CPU: тот же трек определён за
5,55 секунды, включая подготовку фрагмента; синтетическая тишина вернула
отсутствие совпадения за 4,87 секунды. Пользовательские записи и Telegram
в этой проверке не использовались.
