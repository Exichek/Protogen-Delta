# Конвертер видео и аудио

В Mini App откройте «Полезное» → «Конвертер видео и аудио». Выберите файл
на устройстве или перетащите его в область загрузки, укажите формат и нажмите
«Преобразовать». После обработки появятся плеер и кнопка «Сохранить файл».
Telegram 8.0 и новее использует системное сохранение `downloadFile`; в остальных
клиентах доступно обычное скачивание по ссылке.

Видео: MP4, AVI, MOV, MKV. Кодек H.264/yuv420p, до 30 кадров/с, звук AAC;
в AVI звук MP3. Разрешения до 480p, 720p или 1080p; исходное ограничено 1080p.
Размеры не увеличиваются. Поворот смартфонного видео на 90/180/270 градусов
применяется к кадрам. Сохраняются первая видеодорожка и первая звуковая
дорожка; титры, вложения и другие дорожки не переносятся. MP4 и MOV получают
faststart. Видеоперекодирование может снижать качество.

Аудио: MP3 (128/192/320 кбит/с), WAV, FLAC. Можно извлечь звук из видео.
WAV/FLAC сохраняют частоту до 192 кГц и до восьми каналов; для обычного
16-битного PCM сохраняются 16 бит, для остальных источников используется
24-битное представление. MP3 и звук видео ограничены 48 кГц и моно/стерео.
Сохранение в WAV/FLAC не восстанавливает сведения, потерянные в исходном MP3.

MP4, MP3 и WAV проигрываются непосредственно. Для AVI/MOV/MKV готовится
отдельное MP4-превью, для FLAC — MP3-превью. Кнопка сохраняет выбранный
выходной файл. Превью может отличаться разрешением и качеством.

Пределы: 100 МиБ входа, десять минут, 150 МиБ результата, четыре минуты на
загрузку и обработку. Один процесс конвертации, один активный запрос на
пользователя, пауза десять секунд между попытками. На Linux процесс получает
два потока кодирования, 2 ГиБ виртуальной памяти и 180 секунд CPU.
Конвертация не использует языковую модель и не расходует её суточный лимит.

## Временные файлы и доступ

Создание и удаление результата требуют проверенной Telegram `initData`.
Просмотр и скачивание используют случайный 256-битный адрес результата,
действующий пятнадцать минут. Этот адрес даёт доступ к файлу любому, кому
его передали. Адрес не содержит Telegram ID или имени исходного файла.
Плеер получает стандартные ответы HTTP Range; `Cache-Control: private,
no-store` запрещает сохранение в общем кэше.

Одновременно хранится не больше четырёх готовых результатов; у пользователя
один результат. Новый запрос удаляет его прежний результат. Исходный файл
удаляется сразу после успешной обработки. Готовые результаты удаляются
по истечении срока, по кнопке «Очистить» и при завершении сервера. HTTP access
log выключен, чтобы временные адреса не попадали в журнал приложения.

Декодер запускается без секретов бота и модели. Разрешены только локальные
контейнеры видео и аудио; HLS/concat-плейлисты не принимаются. Сеть и запуск
дополнительных процессов запрещены. При отмене или таймауте обработчик
завершается перед удалением временного каталога.

Используется уже установленный PyAV 18.1.0 с библиотеками FFmpeg и кодеками
libx264/AAC/libmp3lame/PCM/FLAC. Отдельные MoviePy/Pydub и исполняемый FFmpeg
не нужны. [Документация PyAV](https://pyav.org/docs/stable/),
[конвертация FFmpeg](https://ffmpeg.org/ffmpeg.html#Detailed-description).

Проверки: `pytest tests/test_media_conversion.py`; браузерный сценарий
`node scripts/check_miniapp_converter.cjs` использует синтетические MP4/MP3
из `.tmp/converter-browser.*`. Он проверяет XHR, настоящий плеер, скачивание,
ошибки, очистку и ширины 320–1280 пикселей с настоящими CSP-заголовками.
