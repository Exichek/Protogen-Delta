# Стиль речи в RP

В «RP и облик» находится чекбокс «Разрешить мат в RP». Настройка применяется
после «Сохранить настройки» и сохраняется при перезапуске бота.

По умолчанию он выключен. В RP-запрос добавляется инструкция говорить без
ненормативной лексики и замаскированных ругательств, независимо от истории
и описания персонажа. При включении модель получает разрешение использовать
мат по контексту, без обязательного мата в каждой реплике и без оскорбления
пользователя вне роли. Это настройка инструкции модели, без замены слов
в готовом ответе регулярными выражениями.

Настройка относится к личному RP-профилю. Групповые профили отдельные,
как персонажи и сцены; чужим пользователям настройка не передаётся.
Обычная беседа вне RP не получает эту инструкцию. Фоновое приглашение
продолжить активную личную сцену учитывает тот же стиль; изменение настройки
во время генерации отменяет устаревшее приглашение.

Остановка сцены сохраняет выбор. «Очистить RP-профиль» и полный `/reset`
возвращают значение по умолчанию. SQLite автоматически добавляет поле
`roleplay_allow_profanity INTEGER NOT NULL DEFAULT 0` к личной и групповой
таблицам без изменения прежних профилей, истории и возрастных ограничений.
API принимает только настоящий JSON Boolean `true`/`false`.
