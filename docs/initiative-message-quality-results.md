# Сравнение самостоятельных реплик 22.10.2026

Восемь синтетических ситуаций, по одному ответу прежней и кандидатной версии:
16 разрешённых попыток API, 16 ответов. Модель настроена как `deepseek-flash`.
Использованы 73 118 входных и 779 выходных токенов. Автоматических повторов,
веб-поиска, Telegram и рабочих диалогов не было. Рабочие квоты не изменялись.

Запросы собраны настоящим `ProactiveMessenger` на временных состояниях.
Внутри пары совпадали системный промпт, выбранный повод, эмоции и часы.
Порядок старого и нового вариантов чередовался. Личные данные в примерах
отсутствуют. RP-запрос совпадал целиком. Все ответы короче 240 символов,
молчания и ошибок API не было; это технические признаки, не оценка качества.

## Что выбрано для установки

Новое задание и контекст трёх прошлых незакрытых инициатив применяются только
к новой мысли, игре и шутливой отсылке. Настроение, вопросы по рассказанным
планам и приглашение в RP сохраняют прежние запросы. Для восьми условий
повторно собраны финальные запросы без API: каждый побайтно совпал либо
с принятым кандидатным запросом, либо с оставленным прежним. Новый
неоценённый вариант задания не подставлялся. Дополнительных вызовов не было.

Обычный голос, личность и общие промпты не менялись. Расписание, суточные
пределы и вероятности выбора повода остались прежними. Новый список содержит
только цитаты доставленных инициатив для неповторения; он не возвращает
весь недавний разговор и не доказывает факты из прежних ответов модели.

Остаются риски неуместной инициативы, выдуманной привычки в прежнем режиме
настроения и неудачного юмора. Их нельзя считать исправленными этим прогоном.
После установки нужна оценка настоящих самостоятельных сообщений пользователем.
