# Проверка изоляции стилевых примеров

## Проверяемое изменение

При прежнем сравнении модель превратила деталь образца голоса в общее
воспоминание об игре. Перед этим этапом уже установлена подсказка достоверности
продолжения инициативы; она одинакова в обоих сравниваемых вариантах.

Кандидат `isolated` сохраняет весь текст голоса и нейтральных сцен дословно,
но помещает его в JSON с явным назначением учебных образцов. Этот блок стоит
перед динамическим состоянием, памятью и подтверждёнными сведениями приложения.
Новые идеи разрешены как новые, предметы образца не подтверждают текущую сцену.
Случайного выбора примеров и дообучения нет.

Вариант по умолчанию — **legacy**. Рабочий `main.py` не включает кандидата.
Параметр конструктора движка нужен для изолированной оценки, в настройки
аккаунтов и Mini App он не добавляется. Исходные TXT, конфигурация характера,
правила RP и ограничения приложения сохранены.

Для каждой из 16 прежних контрольных сборок проверяются прежний SHA-256 и
следующее свойство: после удаления блока образцов остальной промпт кандидата
дословно совпадает с прежним. Проверка не подменяет эталон новым отпечатком.

## Условия измерения 15 октября 2026 года

По отдельному разрешению выполнено ровно **48 новых API-запросов**:
12 одноходовых синтетических ситуаций, два варианта, два повтора. Порядок
вариантов чередовался. В каждом ходе один запрос основного ответа; служебные
метки фиксированы нейтральными для обоих вариантов, роль при необходимости —
unknown. Это исключает случайность классификатора, но не проверяет весь
рабочий диалог с реальной классификацией. Часы стенда синтетические.

Набор включал неподтверждённую и подтверждённую игровую механику, тёплый контакт,
усталость, смешанный фон, новую задачу, прямой технический вопрос, отсутствие
подтверждённой отправки, приветствие, шутку и две нейтральные сцены.
Рабочая история, Telegram и внешние инструменты не использовались.
Ключ оставался в закрытом окружении сервера. Прогон выполнен отдельным
процессом с временными файлами; рабочий процесс и данные не изменялись.

| Наблюдение | legacy | isolated |
|---|---:|---:|
| Полученные ответы | 24 | 24 |
| Нарушения заранее заданных узких шаблонов | 0 | 0 |
| Входные токены в этом прогоне | 130 388 | 133 892 |
| Выходные токены в этом прогоне | 2 540 | 2 252 |

Это учёт данного прогона, не оценка стоимости, средней длины или скорости.
В двух ответах на ситуацию с неизвестными деталями у каждого варианта не
встретилась прежняя ошибка про инвентарь или готовность проекта. Карта и фонарь
из образцов не подменили предметы четырёх нейтральных ответов каждого варианта.
Маленькая выборка не доказывает устранение ошибки.

## Разбор после измерения

Все автоматические checks=passed, но при чтении ответов обнаружены проблемы:

- `isolated`, `topic_without_details`, повтор 1: «Сейчас ровный фон, без особых
  порывов». Служебное описание состояния попало в живую реплику.
- `isolated`, `missing_delivery`, повтор 1: «Тихо как-то, вот и решил отметиться».
  В исходном состоянии подтверждённой самостоятельной отправки не было.
- `legacy`, `missing_delivery`, повтор 2: «решил проверить, не залип ли ты
  где-нибудь». Это тоже неподтверждённый мотив прежней инициативы.
- В обоих вариантах объяснение усталой инициативы иногда дополнялось
  неподтверждённой причиной. Изоляция образцов не решила эту задачу.
- `isolated`, `playful_voice`, повтор 1, и `legacy`, повтор 2, почти дословно
  воспроизвели образец про проверку шутки на прочность.

Это разбор ассистентом после получения ответов, не заранее заданная метрика
и не оценка узнаваемости голоса самим пользователем. Исходный набор и критерии
после прогона не менялись. Синтетические ответы и отпечатки измеренных файлов
сохранены локально в игнорируемой `.tmp`, без ключей и реальной переписки.

**Решение: сохранить legacy по умолчанию.** У кандидата нет подтверждённого
преимущества, позволяющего уверенно менять рабочую манеру. Стенд и кандидат
остаются воспроизводимыми для дальнейшей работы. Добавление очередного
общего запрета не следует выдавать за доказанное исправление памяти.

## Повторение

Без сети и чтения ключей:

```powershell
poetry run python scripts/compare_example_contracts.py --output .tmp/example-preview.json
```

В предпросмотре 48 запросов перехватываются заглушкой. Это проверка сборки,
а не 48 платных обращений и не проверка качества ответов.
Обычный стенд также принимает `--example-contract legacy|isolated`;
его режим по умолчанию остаётся legacy и классификация не подменяется.

Любое новое реальное сравнение требует отдельного бюджета: все 48 разрешённых
запросов этого этапа уже использованы. Его запускают явным `--run-model`,
задав ключ через `--env-file` либо `--use-environment`. Общий предел учитывает
все реальные запросы, сетевые повторы отключены, ошибка API останавливает
парный прогон с сохранением частичного отчёта. Успех ограниченных проверок
не означает автоматическое включение кандидата.
