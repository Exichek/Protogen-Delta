# Возрастное ограничение и очистка разговорных данных

Подтверждён обход: возрастное заявление устанавливает `age_restricted`, но
прежний полный сброс удалял строки состояний и обнулял поле в RAM. После
сброса можно было снова выбрать взрослый режим. Это ошибка реализации,
а не возможность проверить реальный возраст по словам.

Отдельная таблица `age_restrictions` в `user_states.db` хранит только Telegram ID
ограниченного аккаунта. Даты рождения, возраст и текст заявления не записываются
в эту таблицу. При запуске существующие флаги из личных и групповых состояний
переносятся идемпотентно. Сброс разговорных данных таблицу не удаляет.
Ранее потерянный флаг восстановить из отсутствующей записи невозможно:
переписка и архив для этого не анализируются.

Загрузка накладывает ограничение даже при отсутствии строки разговорного
состояния. Устаревшее сохранение `age_restricted=False` не снимает ограничение;
проверка и запись выполняются под SQLite `BEGIN IMMEDIATE`. В RAM ограничение
тоже переживает сброс и удаление неактивного состояния. У других аккаунтов
режим не меняется. Нового пользовательского метода снятия ограничения нет.

Регрессии проверяют заявление «Мне 15 лет» → сброс → кнопку «Мне есть 18»,
сброс после холодного запуска, повторный запуск после удаления строк,
группы, вытеснение RAM, миграцию старых флагов и устаревшую запись взрослой
сцены. Они используют временные базы и моки, без Telegram и API модели.

В `/start` и `/help` добавлено постоянное короткое уведомление о передаче
задачи, выбранной истории и нужных вложений внешнему API ИИ. Подробная
локальная команда `/privacy` доступна в меню и не вызывает модель. Она
различает короткую историю и полный архив, который по умолчанию выключен
и включается только для указанных администратором аккаунтов.

Подтверждение `/reset` перечисляет исключения: счётчики расходов API,
отдельный признак ограничения и существующие резервные копии. Команда
не удаляет сообщения в Telegram или данные у внешнего провайдера.
Дообучение, личность, голос и правила сцены этой правкой не меняются.
