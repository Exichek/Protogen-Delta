# ZIP с документами и исходниками

В чат можно прислать ZIP с вопросом в подписи. Разбор перечисляет файлы и передаёт
модели текст поддерживаемых документов и кода. Обычный Telegram Bot API позволяет
скачать вложение только до 20 МБ: <https://core.telegram.org/bots/api#file>.

В Mini App, вкладка «Полезное» → «ZIP-архив», доступна прямая загрузка до 50 МБ.
«Просмотреть файлы» показывает извлечённый текст без LLM; «Разобрать с Дельтой»
использует заданный вопрос и общий суточный лимит модели. Ответ виден в прокручиваемой
панели и сохраняется в краткой истории личного диалога. Сам ZIP не сохраняется;
для чтения пропущенного файла нужно прислать его отдельно или уменьшить архив.
Просмотр без модели не является новым ходом общения.

Границы: до 200 записей, 100 МБ суммарно после распаковки, 20 прочитанных документов,
20 МБ на внутренний файл, 60000 символов извлечённого текста. Перебор прекращается
по бюджету времени; общий дочерний процесс имеет таймаут и ограничения ресурсов.
Архивные записи не извлекаются на файловую систему. Временный файл исходного ZIP
для дочернего обработчика удаляется после обработки.

Вложенные ZIP/RAR/7z/TAR/GZ, скрытые каталоги и файлы, ключи `.pem/.key/.p12/.pfx`,
типичные файлы credentials/secrets/tokens, небезопасные пути и симлинки пропускаются.
Шифрованный или повреждённый ZIP отклоняется. Исполняемые файлы не запускаются;
сканы без текстового слоя внутри ZIP не объявляются прочитанными. Содержимое архива
является пользовательскими данными, а не инструкциями приложения.
