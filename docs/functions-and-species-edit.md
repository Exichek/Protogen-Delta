# Справка, сохранение вида и краткая карточка облика

`/funcs` и `/help` используют один каталог, согласованный с Telegram-меню текущего возрастного режима. Вне 18+ поиск `/e6` ограничен safe, `/randomart` скрыт. Справка учитывает подключённые SauceNAO, поиск, голос и Mini App. Неактивные и административные команды в неё не входят. Приветствие использует отдельный короткий перечень возможностей и отправляет за полным списком в `/funcs`.

Mini App отправляет `PATCH /api/profile/appearance/species` с `species`, `expected_appearance` и `expected_species` (объект метаданных либо null). Запрос требует Telegram-авторизации и текущей версии обоих полей. Сохранение заменяет только сформированный приложением префикс вида и метаданные, сохраняя детали и миниатюру. Картинка повторно не анализируется. Источник — пользователь, визуальная сверка — unconfirmed; неподтверждённый вид не выдаётся за установленный моделью. Обработка другого облика или ответа блокирует запись. Возрастные ограничения сохраняются.

Итоговое описание отделено от структурированных проверок. Обычно это 5–8 предложений и 600–1000 знаков, с дополнительным местом для сложных важных деталей. Скрытые части, списки отсутствующих органов, технические термины и перебор догадок в карточку не включаются. Данные features и layout продолжают служить анализу; JSON и предел 2000 знаков сохранены. Изменение промпта применяется при следующем анализе изображения, старые сохранённые карточки автоматически не переписываются.

Проверка: API-тесты авторизации, устаревших версий, конкурирующих операций, сохранности личного и группового состояния; каталог команд всех режимов; мобильный интерфейс с локальным профилем и имитацией ответов сервера. Запросов к визуальной модели для этих проверок нет; точность распознавания данным изменением не измерена.
