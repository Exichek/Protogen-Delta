# Сохраняемое настроение

Настроение и отношения записываются в `user_states.db` отдельно для личного чата и
каждой пары пользователь/группа. Перезапуск сохраняет показатели. Очистка короткой
истории их не сбрасывает; полный сброс профиля удаляет состояние.

Существующие тепло, раздражение, игривость, знакомство, доверие, привязанность и
обида сохраняют прежние правила. Добавлены радость, интерес, грусть, тревога,
уверенность и усталость в диапазоне 0–1. Используются существующие классификаторы
настроения/оскорбления и простые сигналы сообщения; дополнительных запросов к модели нет.
Это приблизительная модель поведения персонажа, а не оценка психического состояния человека.

Поддержка и игра повышают радость, сообщение о результате — уверенность, вопрос —
интерес, конфликт — тревогу. Явные слова о грусти и страхе добавляют соответствующий
оттенок сопереживания. Цитаты и код исключены из поиска простых сигналов.
Последние восемь причин сохраняются как тип события и дата, без текста сообщения.
Новые положительные показатели и дополнительное усиление отношений с создателем
растут не чаще одного раза за 15 минут. Старые правила отношений не меняются.
Самостоятельные сообщения бота не усиливают отношения сами по себе.

Время постепенно снижает интенсивность: молчание не создаёт обиду или тревогу.
Приложение передаёт состояние и причины в основной ответ и самостоятельные
сообщения. На прямой вопрос о настроении показатели доступны даже до первого
события. Промпт запрещает выдумывать прошлые поступки и непрерывные занятия между
запросами; точные реплики ищутся в архиве.

`CREATOR_ID` продолжает действовать. В `CREATOR_IDS` можно перечислить дополнительные
ID через запятую. Роль проверяется по Telegram ID из обновления, а не по словам
«я создатель». Истории разных аккаунтов не объединяются; роль не выдаёт
администраторские права автоматически.

Миграция добавляет один JSON-столбец к существующим таблицам. Для прежних записей
начальная радость выводится из тепла/игривости, уверенность — из доверия;
исторические причины не придумываются. Резервные копии базы включают новое поле.
