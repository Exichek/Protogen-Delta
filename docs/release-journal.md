# Журнал установленной сборки

`config/data/release_journal.json` содержит подготовленные разработчиком заметки
текущей сборки: идентификатор, дату заметки и конкретные изменения. Он включается
в пакет при сборке. Это не автоматический пересказ полного Git-журнала и не дата
установки на сервер; заметку нужно обновлять вместе с функциями.

В личном диалоге подтверждённого создателя журнал автоматически передаётся в
контекст каждого ответа. Для обычной инициативы новая заметка может стать поводом
ненавязчиво спросить о функции. После успешного текстового ответа версия отмечается
для этого аккаунта в `memories.db`, таблица `release_journal_seen`; самостоятельный
стикер заметку прочитанной не делает. Другие аккаунты и группы этот блок не получают.
Просмотр помеченной заметки в последующем вопросе остаётся доступен.

Передаются только безопасные текущие счётчики polling и его доступности. Сырые
логи, ключи, окружение и чужие сообщения не читаются. Общий счётчик ошибки не
объясняет причину недоставки конкретного ответа: без подтверждений Дельта должен
сказать, что причина неизвестна.

Журнал не предоставляет права на новые функции. Чтение исходников, архив и
избранное по-прежнему зависят от отдельных настроенных списков Telegram ID.
