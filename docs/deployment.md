# Запуск Mini App на сервере

Нужны Linux-сервер с Docker Compose и домен или поддомен. Публичная Mini App
обслуживается Caddy через HTTPS, бот и SQLite работают в контейнере `delta`.
Пример поддомена: `delta.example.com`. Сам домен не должен содержать `https://`
или путь. Перед настройкой нужны название хостинга и фактический домен.

1. В панели DNS создать A-запись поддомена, указывающую на IPv4 сервера.
   Если есть AAAA, она тоже должна вести на этот сервер.
2. Разрешить входящие TCP-порты 80 и 443 в панели хостинга и firewall сервера.
3. Скопировать репозиторий на сервер. Скопировать `.env.example` в `.env`,
   вписать секреты прямо на сервере и задать `MINI_APP_DOMAIN=delta.example.com`.
   `compose.yaml` сам задаёт URL, включает Mini App и локальный OCR.
4. Если бот уже работает, остановить его перед новым запуском: одному токену
   нужен один polling-процесс. Сделать резервную копию прежнего `DATA_DIR`.
   Новый named volume изначально пуст; прежние данные нужно перенести до
   запуска, иначе пользовательские профили в новом экземпляре будут пустыми.
5. Проверить и запустить:

   ```sh
   docker compose config --quiet
   docker compose up -d --build
   docker compose ps
   docker compose logs --tail 30 delta
   ```

6. Проверить `https://delta.example.com/health`: ожидается `{"ok": true}`.
   Caddy получает и обновляет сертификат автоматически, если DNS и порты
   настроены правильно ([документация](https://caddyserver.com/docs/automatic-https)).
7. В личном чате с ботом открыть `/menu` → «Открыть Mini App». В обычном браузере
   профиль закрыт: нужна подпись `initData`, которую предоставляет Telegram.
   Проверить сохранение настроек, чужой профиль и повторный запуск.

Обновление: `git pull`, затем `docker compose up -d --build`. Не удалять volumes
при обновлении. Остановка: `docker compose down` (без `-v`). Данные SQLite и
сертификаты переживают пересоздание контейнеров.

Секреты хранятся в `.env`, этот файл не включается в Git и Docker-образ.
Для Brave можно смонтировать файл ключа read-only и задать его путь внутри
контейнера через `BRAVE_SEARCH_API_KEY_FILE`. После выдачи нового ключа сначала
проверить поиск с ним, затем отозвать старый в панели Brave.

Пока не проверены реальные DNS, сертификат и вход в Mini App на сервере пользователя:
конфигурация готова, но публикация не считается завершённой.
