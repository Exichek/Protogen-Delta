# Ответ после отправленного обзора

Обзор кода отправляется отдельным фоновым маршрутом. Его доставка уже сохранялась,
но в обычный запрос модели попадала только цитатой в системном контексте. Последней
репликой истории могла оставаться старая игра. Поэтому короткое «Ого, разберёмся»
получало противоречивый контекст и могло возобновить игру.

Теперь сервис возвращает отдельно сведения об обзоре и подтверждённый текст,
который новее сохранённого диалога. Сборка запроса добавляет этот текст последней
репликой assistant перед текущим сообщением. Входящая команда пользователя не
выдумывается. Запись в рабочую историю не создаётся задним числом, повторной
доставки и генерации обзора нет. После нового обычного хода старый отчёт больше
не переставляется в конец. По прямому вопросу об обзоре остаётся прежний контекст.

Используется только запись успешной доставки для этого администратора в личном
чате, младше суток. Отчёт из неудачной генерации, служебная разметка, чужой чат и
удалённая запись не становятся последней репликой. Для длинного отчёта передаётся
до 3500 символов, с указанием в контексте, что пропущенное нельзя придумывать.
Подтверждение отправки не доказывает истинность замечаний или применение правок.

Явный ответ на другое сообщение и пересылка используют собственный контекст.
Активная RP-сцена и обзор возможностей не получают отчёт в историю. Повторный
просмотр старого изображения отключён на ходе с новым отчётом.

Регрессионные проверки воспроизводят последовательность «старая игра — обзор —
короткий отклик», восстановление записи после перезапуска, границы чатов и
фактический порядок ролей в запросе SDK. API подменён, платных вызовов нет.
Это проверяет сборку контекста; качество произвольного ответа модели не гарантируется.
