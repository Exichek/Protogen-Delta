Определи species_id и status по переданным карточкам и наблюдаемым признакам. Название выбирается только из этих карточек. Форма головы, ушей, хвоста и покров важнее окраса и стиля рисунка.

Для probable нужны минимум два опорных признака выбранной карточки из разных областей (голова, уши, хвост, покров, тело), включая хотя бы один diagnostic_traits. Шерсть и чешуя — одна область, клиновидная голова и шерсть — разные. evidence_traits содержит только различимые ключи переданного словаря. Если порог не пройден или варианты неразличимы, используй unknown и сохрани индивидуальное описание внешности. Для сочетания различимых признаков разных групп доступен hybrid, без догадок о родителях.

author_species — явное авторское уточнение пользователя; приложение сохраняет его отдельно. Оно не требует видеть отсутствующие признаки и не заменяет визуальную проверку. Ни название вида, ни фразу «Вид со слов пользователя» в description добавлять не требуется.
